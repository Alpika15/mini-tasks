# 🎭 Face Detection using OpenCV & Python

A simple real-time face detection mini project built using **Python** and **OpenCV**.
This project uses the webcam to detect human faces and draws a rectangle around them in real time. 📷✨

## 🚀 Features

* 🎥 Real-time webcam face detection
* 🧠 Uses OpenCV Haar Cascade Classifier
* 📦 Lightweight and beginner-friendly project
* 🖼️ Draws bounding boxes around detected faces
* ⌨️ Press `q` to exit the camera window


## 🛠️ Technologies Used

* 🐍 Python
* 👁️ OpenCV
* 💻 VS Code

## ▶️ How to Run

1️⃣ Install OpenCV

```bash
pip install opencv-python
```

2️⃣ Run the project

```bash
python main.py
```

## 📌 Note

This project performs **Face Detection**, not full **Face Recognition**.
It can detect faces but does not identify specific people.
